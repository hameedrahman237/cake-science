## 🌍 Deploy to GitHub Pages

1. Create a GitHub account at github.com
2. Create a new repository (e.g. `cake-science`)
3. Upload all files
4. Go to **Settings → Pages**
5. Under **Source**, select `main` branch → `/root`
6. Click **Save** — your site is live at `https://yourusername.github.io/cake-science`

---

## 💡 Tips

- All content is saved in `localStorage` — no backend needed
- Images uploaded via admin are stored as base64 (may use browser storage)
- For large image galleries, consider hosting images on Google Drive or Imgbb
- To change admin password: edit `ADMIN_PASS` in `js/admin.js`
